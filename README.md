# Ethereal Game Studios

Home of Ethereal Games' Roblox projects.

## About

Ethereal Game Studios builds games on [Roblox](https://www.roblox.com/). This
repository holds the source code for our Roblox projects.

## Status

The project is in its early days. Game code will be added here as development
gets underway.

## Contributing

1. Create a new branch from `main` for your change.
2. Commit your work with a short, descriptive message.
3. Push the branch and open a pull request against `main`.
4. Ask a teammate to review it, then merge once it's approved.
